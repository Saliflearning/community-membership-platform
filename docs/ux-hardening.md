# UX Hardening

The platform is civic/community identity infrastructure. Trust matters more than feature count.

## Onboarding

- Keep registration to clear steps: identity, community, payment, card.
- Explain photo privacy before upload.
- Use plain-language errors.
- Keep French as default and English available.
- Show local identity markers without clutter.

## Accessibility

- Large touch targets.
- Visible focus states.
- Labels on every field.
- High contrast text.
- Avoid tiny helper text as the only instruction.
- Test keyboard-only registration and admin flows.
- Test mobile viewport before community pilots.

## Admin UX

- Super admin views everything.
- Scoped admins see only their own operational work.
- Avoid dense enterprise tables until real admins need them.
- Favor clear queues: pending payments, failed cards, support tickets, reassignments.

## Email

Emails are part of trust. They should use consistent branding, short copy, clear next actions, and French default language.
