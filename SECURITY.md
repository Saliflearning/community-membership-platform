# Security Policy

## Reporting

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository and include affected
routes, reproduction conditions, impact, and a minimal proof of concept.

Do not submit real personal data, payment details, credentials, or provider
configuration while testing.

## Scope

The supported release is the current protected `main` branch. The public demo
is a read-only synthetic showcase. Production provider environments operated by
third parties are outside this repository's disclosure scope.

## Response goals

- Acknowledge a complete report within five business days.
- Validate severity and affected versions before public discussion.
- Coordinate remediation and disclosure without exposing member information.
